# Project thumbnails

Put your project thumbnail images in this folder.

The Projects page currently expects these filenames:

- `ezy-bite.jpg`
- `course-corner-kenya.jpg`
- `course-corner-learn.jpg`
- `lostnfound-uoem.jpg`
- `fgck-githurai-44.jpg`

If your images use different names or extensions (e.g. `.png`), update the `<img src="...">` paths in `assets/pages/projects.html` accordingly.
